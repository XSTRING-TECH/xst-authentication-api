# Security Policy

## Reporting a Security Vulnerability

If you believe you have identified a security vulnerability in software or other material published by XSTRING TECH, please report it privately rather than creating a public GitHub issue.

Please provide enough information for us to understand and reproduce the issue, including:

* The affected product, version or release.
* A description of the vulnerability.
* Steps to reproduce the issue, where available.
* Any relevant logs, screenshots or other supporting information.

Please do not include passwords, private keys, Client Secrets, personal information or other sensitive information unless it is necessary to demonstrate the vulnerability.

We will review reported vulnerabilities and, where appropriate, work to address the issue and provide an update.

For security reports, use GitHub's private vulnerability reporting facility where available, or contact:

**[info@xstring.tech](mailto:info@xstring.tech)**

Please do not publicly disclose a vulnerability before we have had a reasonable opportunity to assess it.
